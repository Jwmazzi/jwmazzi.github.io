FOSS4G At Home

Bird City has given me a stable stream of solid projects. Buidling a map for Springfest was good because it meant we had something to start from for this grant. We only need to demonstrate how the planting sites coincide with the areas identified by DNR. Getting quick exports for review (above) was easy with the layout tools in QGIS. I suspect that I will not use Inkscape for this, but will instead work on some basic Python tooling with geopandas. I'm still trying to figure out how I want to work with PostGIS/GeoServer locally, so for this project, since it was relatively simple, I just did my processing in QGIS and saved the outputs to a GeoPackage. Importing my data into PostgreSQL, running via Docker, and doing the calculations was my approach for doing the canopy analysis.
